---
title: Components
description: Inputs, overlays, and layout pieces for PREDICT interfaces, built on Base UI.
---

The general-purpose building blocks of the PREDICT design system: buttons, inputs, menus, dialogs, tables, charts, and the rest of the interface. Pick one from the sidebar to see its demos, usage, and props.

All of them:

- **Follow the theme.** Colours come from the tokens in `globals.css`, so they work in light and dark mode. See [Colours](/docs/design/colors).
- **Use Inter only.** Type sizes come from the scale in `typo.css`. See [Typography](/docs/design/typography).
- **Are accessible by default.** Keyboard, focus, and screen-reader behaviour come from Base UI.

Import them from `@workspace/ui/components/<name>`:

```tsx
import { Button } from "@workspace/ui/components/button"
```

For health-specific pieces, such as the bio clock and the age bar, see [PREDICT UI](/docs/ui/bio-clock).
